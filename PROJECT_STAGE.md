## 🚀 Запуск проекта

```bash

# 2. Запустить на iOS
flutter run -d ios

# 3. Запустить на Android
flutter run -d android
```

## 🔧 Настройка Firebase (опционально)

Для полной функциональности Firebase:

1. Создайте проект на [Firebase Console](https://console.firebase.google.com/)
2. Добавьте iOS и Android приложения
3. Скачайте конфигурационные файлы:
   - iOS: `GoogleService-Info.plist` → `ios/Runner/`
   - Android: `google-services.json` → `android/app/`
4. Настройте Authentication (Email, Google, Apple)
5. Создайте Firestore базу данных
